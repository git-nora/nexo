# NEXO – «Tu familia, siempre cerca»

Asistente de mesa para adultos mayores. La familia manda mensajes de voz y recordatorios
(medicación, cumpleaños) desde una app web; NEXO avisa con luz y sonido, y la persona
responde con su voz apretando un botón. También tiene botón SOS y aviso por inactividad.

Proyecto Integrador – Lassalle Nora y Hernández Andrés.

## Carpetas

| Carpeta | Qué hay |
|---|---|
| `app/` | App web instalable (PWA) para la familia, hecha con Vue 3. Se publica con GitHub Pages. |
| `simulacion/` | Programa del dispositivo (C++ para ESP32-S3) y circuito para simularlo en Wokwi. |
| `documentacion/` | Informe del proyecto (se agrega al terminarlo). |

## Probar la app

Publicada en GitHub Pages: abrir la dirección `/app/` del sitio del repositorio desde el
celular y tocar «Agregar a pantalla de inicio» para instalarla.

> Las claves (token del bot de Telegram, números de chat) no se suben al repositorio.
